# SAS `SINH(argument)`

Hyperbolic sine. See the [SAS
documentation](https://documentation.sas.com/doc/en/lefunctionsref/9.4/titlepage.htm)
(Functions and CALL Routines).

## Arguments

  - x:
    
    Numeric value (any real number). A missing value gives a missing
    result.

  - .at:
    
    Internal: source position `c(line, column)` used in log NOTEs.

## Value

A vector with one result per element (arguments are recycled), as the
SAS function returns per observation.

## Differences from R

Missing arguments (including special missing values) give an ordinary
missing value and are reported in the log; R propagates NA/NaN silently
and has no special missing values.

## Examples

``` r
# SINH: each call is explained above it and followed by its result

# SINH is approximate: in strict mode (the default) a direct call stops; these calls
# run with options(sasonr.strict = FALSE) and a warning of class sasonr_strict_warning.
old <- options(sasonr.strict = FALSE)

# The hyperbolic sine of 0 is 0.
sas_f_sinh(0)  # sinh(0) = 0
#> Warning: sasonr: function SINH is approximate
#> This warning is displayed once per session.
#> [1] 0

# The hyperbolic sine of 1 is (e - 1/e) / 2.
sas_f_sinh(1)  # sinh(1) = 1.1752011936438
#> [1] 1.175201

# A missing argument gives a missing result.
sas_f_sinh(NA_real_)  # sinh(.) = .
#> [1] NA

options(old)
```
