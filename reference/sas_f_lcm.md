# SAS `LCM(x-1 <, ..., x-n>)`

Least common multiple. See the [SAS
documentation](https://documentation.sas.com/doc/en/lefunctionsref/9.4/titlepage.htm)
(Functions and CALL Routines).

## Arguments

  - ...:
    
    Integer values. Any missing argument gives a missing result.

## Value

A vector with one result per element (arguments are recycled), as the
SAS function returns per observation.

## Differences from R

Missing arguments (including special missing values) give an ordinary
missing value and are reported in the log; R propagates NA/NaN silently
and has no special missing values.

## Examples

``` r
# LCM: each call is explained above it and followed by its result

# The least common multiple of 4 and 6 is 12.
sas_f_lcm(4, 6)  # lcm(4, 6) = 12
#> [1] 12

# The least common multiple of 3, 5 and 7 is 105.
sas_f_lcm(3, 5, 7)  # lcm(3, 5, 7) = 105
#> [1] 105

# A missing argument gives a missing result.
sas_f_lcm(4, NA_real_)  # lcm(4, .) = .
#> Warning: NOTE: Mathematical operations could not be performed. The result of the operation has been set to a missing value.
#> [1] NA
```
