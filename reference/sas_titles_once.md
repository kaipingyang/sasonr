# TITLE lines and a blank line before a procedure's listing (none when the procedure writes no listing)

TITLE lines and a blank line before a procedure's listing (none when the
procedure writes no listing)

## Usage

``` r
sas_titles_once(titles, lst)
```

## Arguments

  - titles:
    
    The TITLE lines.

  - lst:
    
    The listing lines of the procedure.
