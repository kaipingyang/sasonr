# SAS `SIGN(argument)`

Sign of the argument. See the [SAS
documentation](https://documentation.sas.com/doc/en/lefunctionsref/9.4/titlepage.htm)
(Functions and CALL Routines).

## Arguments

  - x:
    
    Numeric value. A missing value (`.` or a special missing value such
    as `.A`) gives a missing result.

## Value

A vector with one result per element (arguments are recycled), as the
SAS function returns per observation.

## Differences from R

Missing arguments (including special missing values) give an ordinary
missing value and are reported in the log; R propagates NA/NaN silently
and has no special missing values.

## Examples

``` r
# SIGN: each call is explained above it and followed by its result

# A negative number has sign -1.
sas_f_sign(-3)  # sign(-3) = -1
#> [1] -1

# Zero has sign 0.
sas_f_sign(0)  # sign(0) = 0
#> [1] 0

# A positive number has sign 1.
sas_f_sign(2.5)  # sign(2.5) = 1
#> [1] 1

# A missing argument gives a missing result.
sas_f_sign(NA_real_)  # sign(.) = .
#> [1] NA
```
