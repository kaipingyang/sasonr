# SAS `NOTALNUM(string <, start>)`

Position of the first non-alphanumeric character. See the [SAS
documentation](https://documentation.sas.com/doc/en/lefunctionsref/9.4/titlepage.htm)
(Functions and CALL Routines).

## Arguments

  - x:
    
    Character string to search. A numeric value is first converted to
    character with the BEST12. format.

  - start:
    
    Optional numeric start position, default 1. A positive value
    searches rightwards from that position; a negative value searches
    leftwards (towards the beginning) from position |start|, starting at
    the end of the string if |start| exceeds the length. 0, or a
    positive start beyond the end of the string, gives 0.

## Value

A vector with one result per element (arguments are recycled), as the
SAS function returns per observation.

## Differences from R

SAS character values have a fixed length and are padded with blanks;
trailing blanks do not count in comparisons. R strings have no fixed
length.

## Examples

``` r
# NOTALNUM: each call is explained above it and followed by its result

# NOTALNUM returns the first position of a character that is neither a letter
# nor a digit: '!' at 4.
sas_f_notalnum("ab1!")  # notalnum('ab1!') = 4
#> [1] 4

# All characters are letters or digits, so the result is 0.
sas_f_notalnum("abc")  # notalnum('abc') = 0
#> [1] 0

# Negative start -3 searches leftwards from position 3 ('b') and finds '!' at
# position 2.
sas_f_notalnum("a!b", -3)  # notalnum('a!b', -3) = 2
#> [1] 2
```
