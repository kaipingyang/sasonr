# TITLE lines above the listing of a PROC TABULATE step

The titles and a blank line go above the output of a step that prints
one page; titles above an output of several pages fail loud.

## Usage

``` r
sas_tab_titles(titles, r)
```

## Arguments

  - titles:
    
    The TITLE lines.

  - r:
    
    The result of `sas_rt_proc()`.
