# SAS `CHAR(string, position)`

Single character at a position. See the [SAS
documentation](https://documentation.sas.com/doc/en/lefunctionsref/9.4/titlepage.htm)
(Functions and CALL Routines).

## Arguments

  - x:
    
    Character string. A numeric value is first converted to character
    with the BEST12. format.

  - pos:
    
    Numeric position of the character to return. A position below 1,
    beyond the end of the string, or missing gives a blank result.

## Value

A vector with one result per element (arguments are recycled), as the
SAS function returns per observation.

## Differences from R

SAS character values have a fixed length and are padded with blanks;
trailing blanks do not count in comparisons. R strings have no fixed
length.

## Examples

``` r
# CHAR: each call is explained above it and followed by its result

# CHAR returns the single character at position 3, 'c'.
sas_f_char("abcdef", 3)  # char('abcdef', 3) = "c"
#> [1] "c"

# Position 5 is past the end of the string, so the result is blank.
sas_f_char("abc", 5)  # char('abc', 5) = ""
#> [1] " "

# Position 1 returns the first character, 'a'.
sas_f_char("abc", 1)  # char('abc', 1) = "a"
#> [1] "a"
```
