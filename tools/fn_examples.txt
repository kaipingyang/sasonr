# Reference-page examples of the sas_f_* functions (tools/gen_examples.R).
#
# One section per function: "## NAME".  Each call line is a SAS expression; the
# R call is derived from it (sas_f_<name>(...), 'x' -> "x", . -> NA_real_,
# .A -> sas_missing(".A"), date/time literals -> SAS day/second counts) unless
# given explicitly after " => ".  Other lines of a section:
#   glob: <SAS code>   placed before the DATA step (or PROC SQL)
#   pre:  <SAS code>   placed inside the DATA step before the calls
#   mode: sql          the calls are PROC SQL select expressions
#   note: <text>       shown in the example file (e.g. clock-dependent values)
#   desc: <text>       one English sentence shown above the next call: what it
#                      demonstrates and why SAS gives that result
# tools/gen_examples.R programs   writes tests/conformance/fn_examples/<NAME>/program.sas;
# the SAS results come from tools/refresh_gold.py.  All data are made up.

## ABS
desc: The absolute value of a negative number drops the sign.
abs(-3.5)
desc: The absolute value of zero is zero.
abs(0)
desc: A missing argument (.) gives a missing result.
abs(.)
desc: A special missing value such as .A also gives the ordinary missing value (.).
abs(.A)

## ANYALNUM
desc: The search starts at position 1; the first letter or digit is 'a' at position 3, after two blanks.
anyalnum('  ab1')
desc: No letter or digit occurs in the string, so the result is 0.
anyalnum('!!!')
desc: Negative start -3 searches leftwards from position 3: the first alphanumeric character found is '1' at position 2.
anyalnum('a1!', -3)
desc: Start 3 searches rightwards from position 3, which holds only '!', so nothing is found and the result is 0.
anyalnum('!a!', 3)

## ANYALPHA
desc: The first alphabetic character is 'a' at position 3.
anyalpha('12ab')
desc: The string contains only digits, so the result is 0.
anyalpha('123')
desc: Start 3 searches rightwards from position 3 and finds only digits, so the result is 0.
anyalpha('ab12', 3)
desc: Negative start -4 searches leftwards from position 4: the first letter found is 'b' at position 2.
anyalpha('ab12', -4)

## ANYDIGIT
desc: The first digit is '1' at position 3.
anydigit('ab12')
desc: No digit occurs, so the result is 0.
anydigit('abc')
desc: Start 2 searches rightwards from position 2, skipping the '1' at position 1, and finds '2' at position 3.
anydigit('1a2', 2)
desc: Negative start -2 searches leftwards from position 2 ('a') and finds the digit '1' at position 1.
anydigit('1a2', -2)

## ANYLOWER
desc: The first lowercase letter is 'c' at position 3.
anylower('ABc')
desc: All letters are uppercase, so the result is 0.
anylower('ABC')
desc: Negative start -2 searches leftwards from position 2 ('B') and finds the lowercase 'a' at position 1.
anylower('aBc', -2)

## ANYPUNCT
desc: The comma at position 3 is the first punctuation character.
anypunct('ab,c')
desc: No punctuation character occurs, so the result is 0.
anypunct('abc')
desc: Start 3 searches rightwards from position 3, skipping the '!' at position 2, and finds '?' at position 4.
anypunct('a!b?', 3)

## ANYSPACE
desc: The first whitespace character (a blank) is at position 3.

## CAT
desc: CAT concatenates without removing blanks, so the blanks around ' b ' are kept (trailing blanks of the result are not shown).

## COMPARE
desc: COMPARE returns 0 when the two strings are equal.
compare('abc', 'abc')
desc: The strings first differ at position 3; the sign is negative because 'c' sorts before 'd', so -3.

desc: The first difference is at position 3 and 'd' sorts after 'c', so the result is +3.
compare('abd', 'abc')
desc: Modifier i ignores case, so 'ABC' and 'abc' compare equal (0).

desc: The shorter string is padded with blanks; 'c' sorts after a blank, so the result is +3 (first difference at 3).
compare('abc', 'ab')
desc: Modifier : truncates the longer string to the length of the shorter one, so 'ab' and 'abc' compare equal.
compare('ab', 'abc', ':')
