# Verification matrix of formats and informats (tools/gen_matrix.py formats).
#
# "## NAME format|informat N|C [BASE]": BASE is the SAS name (default NAME;
# "-" for the w.d format/informat without a name).  Each case is
#   format:   r = put(<value>, <BASE><w>.<d>)
#   informat: r = input('<value>', [?|??] <BASE><w>.<d>)
#   values: v1 | v2 ...   (SAS expressions for formats, raw text for informats)
#   widths: w ...         (_ = no width; w or w.d; ?? or ? prefix; -l/-c/-r suffix)
#   cases: <value> @ <width spec>     one more case
#   ce: <expression>                  a compile-time error (own session)
# Every value is combined with every width.  All data are made up.
